# Todo App

A simple and modern Todo List web application built with PHP, MySQL, JavaScript, and Tailwind CSS.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Store tasks permanently in MySQL
- Responsive user interface
- Success and delete notifications
- Clean and simple design

## Technologies

- PHP
- MySQL
- JavaScript
- Tailwind CSS
- HTML

## Installation

1. Clone the repository:


git clone https://github.com/bita98/todo-app.git


2. Move the project into your XAMPP `htdocs` directory.

3. Create a MySQL database named:


todo_list


4. Import the required database table.

5. Make sure XAMPP Apache and MySQL are running.

6. Open the project in your browser:


http://localhost/todo-app


## Database Configuration

The project uses the following local MySQL configuration:


Host: localhost
Username: root
Password: empty
Database: todo_list
